# Rottweiler sales page (static, single file)
- index.html + cover-500x800.jpg. No build step; upload both files to any static host.
- Buy buttons -> https://www.checkout-ds24.com/product/751469/ (DS24 itself rejects www.digistore24.com/product/... links, error CUSDM1).
- Trust badge: paste the DS24 "Sales page badge" HTML code between <!-- DS24_TRUST_BADGE --> markers (right after <body>).
  Get it: DS24 Vendor view > My products > Conversion tools > Trust badges tab > Create trust badge >
  Type "Sales page badge", position e.g. bottom bar, Language English, earnings disclaimer No > Save and Update preview > copy "HTML code".
  The Sales Page Footer renders automatically with that badge; the footer placeholder is only a fallback.
- After hosting: paste the page URL into DS24 product > Properties > Sales page. Keep Thank-you page EMPTY (Download Vault delivery).
- Band color is the real Rottweiler cover color (mahogany rust #8B3A1A) on charcoal #2B2D30.
